Switch computers in seconds

Magic Keyboard stores one active Bluetooth pairing at a time. Magic Keyboard Suite makes moving effortless.

1

Release

Click “Release” on your current computer. The app disconnects, forgets the pairing, and remembers your keyboard.

2

Toggle switch

Turn the keyboard's physical power switch off for 2 seconds and turn it back on.

3

Connect

Click “Connect” on your other computer from the main window, macOS menu bar, or Windows system tray.

Built for Mac & Windows workflows

Everything you need, nothing you don't — scoped exclusively to Apple hardware.

Connectivity

Bluetooth, USB & live battery

Works wirelessly or over Lightning / USB-C, with real-time battery percentage in the app, macOS menu bar, and Windows tray.

Layouts

17 Apple layouts & ISO fix

Swaps the physical ISO keys on Windows automatically and imports Apple's 17 official Boot Camp layouts with Authenticode verification.

Shortcuts

Mac shortcuts, Option symbols & media

3 modifier modes, Left Option (⌥) for @ # € [ ] { } \ | ~, word navigation, media keys, and optional Right Option as Fn on Windows.

Native

SwiftUI & WinUI 3 · EN, CA & ES

Two lightweight native apps built from a single shared design source, with live language switching and open-at-login support.

Import the 17 official Apple layouts (Boot Camp)

Download Apple's official Boot Camp Support Software .zip (do not unzip or run setup.exe) and pick it via “Select .zip…” inside Magic Keyboard Suite. The app extracts and verifies only the 17 keyboard layout DLLs.
