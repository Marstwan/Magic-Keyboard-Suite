Guía Windows ↔ Mac

Cómo pasar el teclado de un ordenador a otro en segundos

1
Pulsa «Liberar» en la tarjeta de tu Magic Keyboard en el equipo actual.
2
Apaga el interruptor físico del teclado durante 2 segundos y vuelve a encenderlo.
3
Pulsa «Conectar» en Magic Keyboard Suite en el otro ordenador.

Diseñado para quienes trabajan entre Mac y PC

Dos aplicaciones 100% nativas construidas desde una única fuente de diseño.

Bluetooth y cable USB

Porcentaje de batería en vivo

Consulta la batería exacta de tus teclados conectados tanto en la tarjeta principal como en la barra de menús de macOS y en Windows 11.

ISO

Serigrafía ISO y Boot Camp

Corrige el intercambio físico entre [º ª \] y [< >] en Windows e importa automáticamente las 17 disposiciones oficiales de Apple desde el paquete Boot Camp.

⌥

Símbolos con Option (⌥)

Escribe @, #, €, [, ], {, }, \, | y ~ usando la tecla Option izquierda exactamente igual en macOS y en Windows.

⌘

Atajos con Command (⌘)

Usa tus atajos de Mac en Windows, además de Fn + Retroceso para Supr y ⌘ + Flechas para Inicio/Fin, aplicados exclusivamente a teclados de Apple.

ES · CA · EN

Català, Español e English

Elige el idioma en la pantalla inicial de bienvenida o cámbialo en tiempo real desde la propia aplicación tanto en macOS como en Windows 11.

¿Usas Windows? Importa las 17 disposiciones oficiales de Apple

Por licencia de Apple, las librerías propietarias de teclado de Boot Camp (*A.dll) no se incluyen dentro del instalador. Descarga el archivo .zip oficial desde la web de Soporte de Apple (sin descomprimirlo ni ejecutar su setup.exe) y selecciónalo pulsando «Elegir .zip…» dentro de Magic Keyboard Suite: la app extraerá y verificará sola únicamente las disposiciones de teclado.

Generar tu propio .dmg en macOS

Requiere Xcode Command Line Tools y Python 3:

git clone https://github.com/Marstwan/Magic-Keyboard-Suite.git cd Magic-Keyboard-Suite ./macos/build.sh --dmg
Compilar desde el código fuente

Generar tu propio .msi en Windows 11

Requiere .NET 8 SDK y Python 3:

git clone https://github.com/Marstwan/Magic-Keyboard-Suite.git cd Magic-Keyboard-Suite powershell -ExecutionPolicy Bypass -File .\windows\build.ps1
